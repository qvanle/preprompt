# preprompt

A small app to manage and reuse prompt templates for personal projects.

## Overview

This repository stores the preprompt application — utilities and configuration for building, organizing, and sharing curated prompt templates.

## Quick Start

1. Clone the repo: git clone https://github.com/qvanle/preprompt.git
2. Inspect the code and run the app as described in project docs (or open an issue for help).
